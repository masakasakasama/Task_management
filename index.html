同期 & バックアップ設定

端末間で自動同期するには GitHub のトークン を1つ貼るだけ。
① Personal Access Tokens (fine-grained) を新規作成 → ② 「Account permissions」→「Gists」を Read and write に設定 → ③ 生成された github_pat_… を下に貼り付け
※ Repository permissions は変更不要。トークンはこの端末のブラウザにのみ保存されます。
他の端末でも同じトークンを貼ると、自動で同じデータに繋がります。

このQRコードを別の端末のカメラで読み取って開くだけで、トークンが自動でコピーされて同期が始まります。
（カメラで読めない場合は下のリンクをコピーして、その端末で開いてください）

⚠️ このリンクには同期トークンが含まれます。SNS等への投稿はしないでください。
